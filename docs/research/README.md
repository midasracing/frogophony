# Frogophony — trwała baza referencyjna
Audyt 2026-11-24, runda 2. Dokumentacja robocza, nie certyfikacja pedagogiczna. Zapisano własne syntezy i odnośniki, nie kopie cudzych podręczników.

## Kolejność korzystania z dokumentów
1. [Rejestr źródeł](sources.json): typ, adres, status sprawdzenia i ograniczenia.
2. [Program i rekrutacja](curriculum-audit.md): matryca pokrycia i poprawki do planu.
3. [Kompendium muzyczne](music-reference.md): reguły, przykłady, wyjątki i wymagania dla autorów.
4. [Silniki i testy](engine-audit.md): ocena bibliotek, ryzyka, kryteria wdrożenia.
5. [Przypadki wzorcowe](golden-cases.json): autorskie dane testowe, do zaimplementowania i sprawdzenia.
6. [Proces wydawniczy](quality-policy.md): kwalifikacja treści, licencje, recenzje, dostępność.
7. [Raport zmian](audit-log.md): błędy, rozstrzygnięcia i luki.

W razie sprzeczności z pierwszym blueprintem obowiązują poprawki z tej rundy. Nie deklarować zgodności z całym szkolnictwem, dopóki macierz wymagań nie zostanie zamknięta. Status source-reviewed oznacza weryfikację materiałów źródłowych, nie zatwierdzenie przez nauczyciela ani test wykonany na urządzeniu.
